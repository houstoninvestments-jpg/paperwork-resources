# Paperwork Resources

Free, official sources for common U.S. and travel paperwork, with plain-English guides.

## Apostilles (U.S. state offices)
- U.S. Department of State (federal documents, e.g. FBI checks): https://travel.state.gov/content/travel/en/records-and-authentications/authenticate-your-document.html
- State-by-state apostille guides: https://paperworkpath.pages.dev/by-state · What is an apostille: https://paperworkpath.pages.dev/what-is-an-apostille
- FBI background check apostille: https://paperworkpath.pages.dev/apostille-fbi-background-check
